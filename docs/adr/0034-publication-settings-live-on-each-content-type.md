# 公開設定は各コンテンツが自身の属性として持ち、種別を跨ぐ掲出台帳を置かない

Status: Accepted

公式サイトに載る記事・口コミ（将来は写メ）は、公開／非公開の切替・公開期間・表示順を共通の公開設定として持つ。これを種別を跨ぐ一つの掲出台帳（種別 + コンテンツ ID を指す汎用表）にはせず、各コンテンツの表に同じ値オブジェクトとして埋め込み、意味と検証規則だけを一箇所で共有する。台帳方式は多態参照のため外部キーが張れず、コンテンツ削除で孤児行が残り、店舗の明示（ADR 0031）を台帳側でも二重に保証することになる。しかも掲出の前提は種別ごとに異なり（口コミは承認・公開許可・未取り下げ、記事は無し）、台帳が統一できるのは最も浅い層だけである。

## 検討した選択肢

- 種別を跨ぐ掲出台帳: 一覧を種別横断で並べやすいが、上記の理由で不採用。横断一覧の要件は無い。
- 種別ごとに自由: 「同じ語が種別ごとに違う意味」を再生産するため不採用。

## 帰結

- CastProfile は公開設定を持たない。キャストの掲出の終わりは期限ではなく退店で決まり、既存の PUBLISHED / UNPUBLISHED と表示順で足りる。
- 公開範囲（誰に見せるか）は持たない。公式サイトは店舗ごとで、コンテンツの所有店舗も一つだから。会員限定などが必要になったら新しい要素として足す。
