# 匿名件数照合の合成例

すべて架空の入力・期待報告であり、分類キーは各試験で指定する範囲だけを表す。顧客・受注・明細・キャスト・残高の実際の実体対応、集計粒度、一対一映射を定義または承認するものではない。

- `matched.input.json` / `matched.expected.json`: 指定した五分類の件数一致。期待するCLI終了コードは0。
- `exemption-mismatch.input.json` / `exemption-mismatch.expected.json`: 旧側customer=10、新側=9、対応表=10、豁免=11。旧側を超える豁免も形式・整数範囲が正しければ独立表示し、必須の入帳先を保持する。差額は-1のままで、期待するCLI終了コードは1。

金額・人工抽様・実移行は両方とも未評価。CLI受け入れ試験が入力から期待報告と終了コードまでを検証する。詳細な上限・拒否ケースは[仕様](../0397-count-reconciliation.md)を参照する。
