# 03: 店舗のアンケートを版管理し、回答を手動受付・訂正する

実装票: [#1007](https://github.com/kanghouchao/Kizuna/issues/1007)。親課題: [#394](https://github.com/kanghouchao/Kizuna/issues/394)。仕様: 394-B アンケートの版管理と回答の手動受付契約案。

状態: **契約・試験面・票の粒度の承認済み。実装・ローカル最終検証完了。CI・CodexレビューはPRで追跡**。

## 背景 / 目的

手元の回答を登録する時点の設問が固定されず、回答の原文・取り下げ・訂正を追えない。店舗担当者が自作した設問版を開始し、既に受け取った回答を記録して、同版の個票と件数を確認できるようにする。

## スコープ

一つの縦切片として、テキスト／単一選択の設問版作成・開始・終了、人工受付、回答詳細・専用履歴、理由付き取り下げと訂正、同版件数をschemaからHTTP・管理画面・実DB試験まで通す。設問文は権限を持つ店員が入力し、プログラムが業務文面を作らない。

## 受け入れ基準

- [x] 独立SURVEY_VIEW／MANAGE／RECORDを既定授与なしで用意し、全操作を現在DBと対象店舗・有効な緊急昇格で検証する。
- [x] 担当者が20問以内のテキスト／単一選択設問を作成・編集し、必須・順序・選択肢を確認して開始できる。
- [x] 同系列の下書き／受付中は各最大一件。開始済みの内容は不変で、旧版を明示的に終了して新版を開始できる。
- [x] 受付中の指定版に手動登録し、取得経路・受領日時・受付者を残す。本人性・匿名性・来店資格は証明したと表示しない。
- [x] 必須設問欠落、未知／重複キー、別設問の選択肢、TEXTと選択肢混在、空回答、不正型／上限／時刻を拒否する。
- [x] 理由付き取り下げは終態。訂正は同版に新回答を作り旧回答を取り下げ、原文を上書きしない。一対一の訂正系列を辿れる。
- [x] 終了済み版には新規受付できないが、既存回答の訂正・取り下げができる。
- [x] 同版のtotal／active／withdrawn件数が単一読取で整合し、訂正や取り下げが契約例どおり反映される。回答者数・回答率とは呼ばない。
- [x] 同キー再生は現在授権を通り、元操作と現在詳細を返す。二重作成・二重訂正・古い成功応答による状態の巻き戻しがない。
- [x] 実PGで機構的店舗隔離・同店参照・並行開始／受付終了／改版／訂正・監査の同一取引と失敗時の巻戻しを確認する。
- [x] 原文は一覧DTOに含めず、設問・回答・理由・入力値がログ／汎用auditへ出ない。
- [x] UIが権限を分け、旧レスポンス・版切替・404/409・結果不明→同キー再確認から回復でき、機密入力をブラウザ永続storageへ保存しない。
- [x] 保持期限は未設定と明示し、匿名保証・永久保存承認・自動消去を実装済みと表示しない。
- [x] 合成データだけでTaskfile、独立レビュー、調整済み専用E2Eを通し、顧客への招待・実送信・報酬付与を行わない。

## 視覚・探索基準

明暗テーマ、390pxと通常幅、キーボード、長い設問と選択肢で版・受付中状態・人工受付の区別が読める。訂正前に旧回答の取り下げと同版固定を示す。取下げを消去と呼ばず、件数は記録件数と明示する。

## 対象外

オンライン本人投稿・匿名保証・招待・資格／頻控・実外部連絡、本人／受注への関連、報酬、口コミ化／公開、複数選択／評価尺度、横断集計・スコア・CSV／export、添付、保持期限による自動消去。完了しても #394 全体を閉じない。
