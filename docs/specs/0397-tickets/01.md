# 01: 外部の匿名集計を三方照合する

**親:** #397（OPEN継続）
**公開票:** #1014
**状態:** 実装・検証中。
**阻害要因:** なし。修訂契約・検証境界・独立Nodeスクリプト・子Taskfile・CI検査の配置は主タスク承認済み。

## 背景 / 目的

同じ条件の旧側基準件数・新側導入件数・ID対応表行数を比較し、欠落や豁免による見かけの一致を防ぐ。分類口径を実データから発明せず、まず合成入力で検証する。

## スコープ

[契約案](../0397-count-reconciliation.md)の一つの縦断切片。上限付きの厳格なUTF-8入力、三方比較、独立した豁免と入帳先の表示、JSON報告と終了コード、境界を通す合成受け入れ試験を一体で扱う。既存Nodeの独立開発スクリプトとして配置し、製品モジュールを新設しない。

## 受け入れ基準

- [x] 入力と出力の契約・配置を技術レビューで承認する。
- [x] 同じ条件の三方が分類別に一致する時だけMATCHEDとする。
- [x] 欠落・重複・負数・小数・溢れ・比較不能を拒否し、部分成功を出さない。
- [x] 豁免の入帳先を必須として独立表示し、差額の控除や重複不明の合計をしない。旧件数超過を業務規則として拒否しない。
- [x] 原始入力1 MiB、配列各1000件、JSON構造64層、件数文字列19桁を守り、無制限の全読込・復号置換・重複キー上書きをしない。
- [x] エスケープ復号後のキー名で重複を拒否し、すべてのINVALIDで安全なpathと空の業務結果だけを返す。
- [x] 未評価の金額・人工抽様・実移行と、外部提供件数だけの証拠範囲を常に表示する。
- [x] 完全入力から報告・終了コードまでの受け入れ試験を既存工具で実行できる。
- [x] ネットワーク無効・入力読取専用の合成試験をTaskから実行しexit codeを記録する。
- [x] #397を閉じず、実口径と金額の未決定事項を残す。
