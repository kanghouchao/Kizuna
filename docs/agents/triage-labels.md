# トリアージラベル

スキルの五つの標準ロールを、課題管理で使用するラベルへ対応付ける。

| 標準ロール | 使用するラベル | 意味 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | メンテナーによる評価が必要 |
| `needs-info` | `needs-info` | 報告者からの追加情報を待っている |
| `ready-for-agent` | `ready-for-agent` | 仕様が明確で、エージェントが自律的に着手できる |
| `ready-for-human` | `ready-for-human` | 人による実装が必要 |
| `wontfix` | `wontfix` | 対応しない |

スキルがロールを指定した場合は、この表の対応するラベルを使用する。課題管理側の名称を変更するときは、「使用するラベル」列を更新する。
